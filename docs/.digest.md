# Project Digest: HarnessKit

## OVERVIEW
Clean Architecture modular em TypeScript/Node.js para orquestração autônoma de TDD com interfaces CLI e Web local (`sdk-web`). Camadas divididas em Domain, Application, Presentation e Adapters/Infrastructure com isolamento hermético de processos.

## CONSTRAINTS & PATTERNS
- REQUIRED: Herança de `AbstractCliRunner` com `writePromptToStdin = true` para streaming de prompts extensos.
- REQUIRED: Servidor web local vinculado estritamente a `127.0.0.1` prevenindo exposição em interfaces de rede.
- REQUIRED: Sanitização obrigatória de variáveis sensíveis de ambiente via `filterSensitiveEnv`.
- REQUIRED: Validação estrita por whitelist (`^[a-zA-Z0-9][a-zA-Z0-9._:/-]{0,127}$`) e níveis de effort em configurações de modelos CLI.
- REQUIRED: Persistência atômica via `AtomicSettingsWriter` para todas as mutações de configurações e estado.
- REQUIRED: Mapeamento 1:1 estrito entre CycleId e SessionId em execuções paralelas com isolamento em Git Worktrees.
- FORBIDDEN: Propagação de tokens, API keys ou senhas em processos filhos ou payloads de telemetria.
- FORBIDDEN: Terminação de processo único sem encerramento da árvore de processos (`taskkill /t` / `SIGKILL`).

## TESTING
- Framework: Vitest ^4.1.10
- Commands: `npm.cmd test` (SDK), `npm.cmd --prefix sdk-web test` (Web), `npm.cmd run test:e2e` (E2E)
- Gated Live Tests: `env AGY_INTEGRATION_TEST=true npm.cmd test`
- Minimum Coverage: 85% global (90% domain/core, 85% app/presentation, 80% infra)
